# Changelog

## v0.2.0

- Volume up/down now also unmutes the speaker if it is muted.

## v0.1.0

- First release: volume, mute, play/pause and next/previous track control
  for a Sonos speaker on the local network.
- Automatic speaker discovery, and re-discovery if its IP address changes.
- Bind any command to a GNOME keyboard shortcut via `sonos.json`.
- Optional autostart at login.
